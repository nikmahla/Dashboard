# Charts & Data Visualization Audit

Review every chart in the dashboard as a Senior Data Visualization Designer.

Analyze:

### Visual Design

* Overall attractiveness
* Professional appearance
* Visual balance
* Modern SaaS standards
* Readability
* Information density

Check if charts feel outdated, plain, or unfinished.

### Chart Container Design

Review:

* Card design
* Borders
* Border radius
* Shadows
* Backgrounds
* Padding
* Internal spacing

Determine whether charts should have:

* Subtle borders
* Elevated cards
* Soft shadows
* Section dividers
* Better visual grouping

Provide exact recommendations.

### Chart Structure

Review:

* Titles
* Subtitles
* Legends
* Tooltips
* Labels
* Axes
* Grid lines

Check if users can understand the chart within 3 seconds.

### Data Visualization Quality

Verify:

* Appropriate chart type
* Appropriate scale
* Data clarity
* Visual hierarchy
* Trend visibility

Suggest better chart types where needed.

### Professional SaaS Comparison

Compare chart quality against:

* Stripe Dashboard
* Datadog
* Grafana
* Vercel Analytics
* Shopify Analytics

Identify missing professional patterns.

### Chart Styling

Review:

* Border visibility
* Card borders
* Chart spacing
* Tooltip design
* Hover effects
* Interactive states
* Loading states
* Empty states

Check whether borders should be:

* Solid
* Subtle
* Dashed
* Accent-colored

Recommend the most professional option.

### Light Mode & Dark Mode

Review:

* Border contrast
* Grid visibility
* Axis visibility
* Tooltip readability
* Hover states
* Legend visibility

Identify theme-specific issues.

### Responsiveness

Test:

* Mobile
* Tablet
* Desktop
* Ultra-wide screens

Check:

* Cropped labels
* Overlapping legends
* Overflow issues
* Unreadable axes

Provide exact fixes.

### Deliverables

For every chart:

1. List all design problems.
2. Assign severity.
3. Explain why it hurts usability.
4. Provide redesign recommendations.
5. Provide exact CSS/Tailwind changes.
6. Suggest border, shadow, spacing, and card improvements.
7. Suggest improvements to make the chart look enterprise-grade and production-ready.
